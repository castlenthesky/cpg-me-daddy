# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a tool to manage versioning and changelogs. Read the full documentation at https://changesets.dev.

We also have a quick list of common questions to get you started engaging with this project in our [FAQ](https://changesets.dev/faq).

## Project rule

Any PR that changes a package's behaviour adds a changeset (`npm run changeset`); tooling-only PRs (config, CI, scripts, docs) do not. All packages are private for now (`access: "restricted"`, no publish workflow), so `privatePackages` is set to `{ "version": true, "tag": true }` so `npm run version-packages` still versions private packages and `npx changeset git-tag` (run from a later release script; `changeset version` itself never creates tags) can tag them. `commit` is false so versioning stays a reviewed, explicit commit. JSON cannot hold comments, so these config rationales live here.
