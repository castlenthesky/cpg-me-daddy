# cpg-me-daddy

Bare-bones VS Code extension scaffold. See [`docs/README.md`](docs/README.md) for the documentation
map — start with [`docs/STATUS.md`](docs/STATUS.md) for what's currently true, or
[`docs/plans/unified-architecture.md`](docs/plans/unified-architecture.md) for the target
architecture.

## Running

```
bun i
bun run compile
```

Then press F5 in VS Code to launch the Extension Development Host.
