# apps/vscode: agent notes

Status (U3.1.1 part 4, BMO-52): REAL: the extension. `extension.ts` is the composition root; `adapters/` holds C-EXT's three (WebviewTransport with the WebviewPanel and its serializer, SourceOpener, FilesystemProbe); `graph-session.ts` holds the flows of `cpg.openGraph`, `cpg.verify`, a restored panel and deactivation (controller decision 38); `graph-panel.ts` is the one panel; `workspace-probe.ts` admits files as the walker does; `workspace-config.ts` finds and reads `cpg.config.yaml`. From parts 1 to 3: C-EXT's host types, `PanelGraphHost`, verify and its scheduler, the status and diagnostics data, the theme, the panel's HTML. SEAT: within `verify`, `identity-invariants` and `resolution-health` are `unavailable` until U6c, as in the engine. U4.2.2 (BMO-132, controller decisions 70 to 74): `graph-session.ts` keeps the graph current with ONE `engine.watch` (@parcel/watcher in process, loaded from node_modules; VS Code's file events are not used): ready's graph is an `initial` snapshot and each batch's a latest-wins `catch-up`; a watch that is replaced ends before the next loads anything; `cpg.openGraph` during a live watch only shows the panel; a verify run whose graph moved while it ran is shown nowhere. There are still no graph deltas, so `onDelta` has tests and no product caller (decisions 28, 67). Tests drive the built extension with a stand-in `vscode` (`tools/extension.test.mjs`), and `host-tests/` runs it inside VS Code (U3.1.2, BMO-56; `bun run test:vscode-host`, `docs/outline/08-verification.md` §7).
Layout and rules: `docs/outline/03-architecture.md` §2. Root `AGENTS.md` applies.

- The only place `vscode` may be imported, and here only `extension.ts` and the three adapters (check-deps rule 10). Imports `@cpg/*` front doors only.
- `host-tests/` is built into `dist/host-tests` by `tsc -b` and run by `@vscode/test-cli`, never by vitest. Never start VS Code with a display you did not make: `bun run test:vscode-host` is headless unless `CPG_HOST_DISPLAY=1`. A `pass` of render-reconciliation there proves the bundle loaded and the page reported, not that a picture was drawn (stop-list 124).
- `host-tests/spikes/` are measurements (`bun run spike:vscode-host`), not tests: their numbers live in `docs/outline/06-measurements.yaml`.
